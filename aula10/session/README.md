# Sistema de login com sessões em PHP

Esta pasta reúne o exemplo de login com sessões e a atividade sobre o sistema.

## Arquivos

- login.html: formulário de login.
- valida.php: valida as credenciais e inicia a sessão.
- painel.php: página protegida que exibe o usuário autenticado.
- logout.php: encerra a sessão.
- css/estilo.css: estilos compartilhados.
- atividade.md: questionário com as 30 questões e respostas.

## Como executar

Coloque a pasta em C:\xampp\htdocs\session\, inicie o Apache pelo XAMPP e acesse http://localhost/session/login.html.

Credenciais do exemplo: usuário admin, senha 12345.
